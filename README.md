# Civil Defense Emergency Management System – Mobile App

Android application for citizens and field responders. Citizens can report emergencies; responders receive assignments, navigate to incidents, and upload evidence.

## Overview

- **Citizen Module:** Report an emergency with one tap, send GPS location, receive alerts.
- **Responder Module:** View assigned incidents, get turn‑by‑turn navigation, update incident status, upload photos/videos/voice notes.

Built with **Java** for Android (minimum SDK 24+).

## Prerequisites

- Android Studio (Arctic Fox or newer)
- JDK 11
- Android SDK (installed via Android Studio)
- Backend API running (see `civil-defense-backend`)
